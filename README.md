# 보험/GA 맞춤 채널톡 제안서 — 편집 가이드

각 세일즈가 **자기 잠재고객(GA)에 맞게 텍스트·이미지만 바꿔서** 쓰는 제안서 템플릿입니다.
스토리(1막 경영 → 2막 영업 → 3막 운영) 구조는 그대로 두고, **회사명·담당자·레퍼런스만** 바꾸면 됩니다.

---

## 📁 파일 구조
- **`proposal.html`** — 제안서 본체 (슬라이드 1280×720). **이 파일만 편집하면 됩니다.**
- `index.html` — proposal.html과 항상 동일하게 유지 (GitHub Pages 공유용)
- `img/`, `faces/` — 이미지·인물 사진 (상대경로)

---

## 🖥 로컬에서 열기 / 편집
1. 이 폴더를 **다운로드**(초록 `Code` 버튼 → Download ZIP) 또는 `git clone`
2. `proposal.html`을 **브라우저로 더블클릭** → 바로 보임 (넘길 땐 스크롤)
3. 편집: `proposal.html`을 **텍스트 에디터**(VS Code, 메모장 등)로 열어 아래 항목을 찾아 바꾸기
4. 저장 → 브라우저 **새로고침**

---

## ✅ 바꿔야 할 곳 (체크리스트)
| 바꿀 것 | 에디터에서 찾기(⌘F/Ctrl+F) | 위치 |
|---|---|---|
| **GA 회사명** | `○○ GA` | 1·2·3막 디바이더 인물 소개 (3곳) |
| **담당자·이메일** | `담당 ○○○ · ○○○@channel.io` | 마지막 Thank you |
| **ROI 수치** | ROI 장표 (전부 "예시·가정") | 규모에 맞게 조정 |
| **레퍼런스 로고** | `img/reference.png` 파일 교체 | 3페이지 — 자사 고객사 로고월로 |
| (선택) 인물명 | `본부장님`, `박현우`, `수민` 등 | 필요 시 이름만 |

> 한글은 그대로 입력하세요 (유니코드 이스케이프 X). 이미지 교체는 `img/` 폴더의 같은 파일명으로 덮어쓰면 됩니다.
